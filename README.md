# যুবসংঘ ডিজিটাল — ধাপ ১ (ডিজিটাল সদস্য তালিকা)

বাংলাদেশ আহলেহাদীছ যুবসংঘের ডিজিটাল সদস্য ফরম ও এডমিন প্যানেল।

| অংশ | প্রযুক্তি | ফোল্ডার |
|---|---|---|
| Backend | Spring Boot 3.3 (Java 17), JPA, Spring Security + JWT | `backend/` |
| Frontend | Angular 18 (standalone, reactive forms) | `frontend/` |

## ফিচার

- **পাবলিক লিংক** (`/`) — লগইন ছাড়া যে কেউ সদস্য ফরম পূরণ করতে পারবে। সব লেখা বাংলায়।
  - ১–১৩ নং সব ঘর (নাম, পিতা/মাতার নাম, জন্ম তারিখ, রক্তের গ্রুপ, শিক্ষা, ই-মেইল, দুইটি মোবাইল + কল/WhatsApp চিহ্ন,
    স্থায়ী ও বর্তমান ঠিকানা, সাংগঠনিক দায়িত্ব, সাংগঠনিক মান, শপথের তারিখ)
  - ঠিকানা: বিভাগ → যেলা → উপযেলা → ইউনিয়ন → ওয়ার্ড ড্রপডাউন (সারা বাংলাদেশের ৮ বিভাগ, ৬৪ যেলা, ৪৯৪ উপযেলা, ৪৫৪০ ইউনিয়ন)
  - "বর্তমান ঠিকানা ও স্থায়ী ঠিকানা একই" চেকবক্স
  - সাংগঠনিক দায়িত্ব: প্রথমে স্তর (শাখা/এলাকা/উপযেলা/যেলা/কেন্দ্র), তারপর শুধু সেই স্তরে বিদ্যমান পদবি (ফরমের টেবিল অনুযায়ী)
  - বাংলা অঙ্কে মোবাইল নম্বর লেখা যাবে; একই নম্বরে দ্বিতীয়বার নিবন্ধন করা যাবে না
- **যেলা এডমিন (মিনি এডমিন প্যানেল)** (`/admin`) — শুধু নিজের যেলার সদস্য দেখবে, তথ্য পরিবর্তন, বাতিল ও অনুমোদন করতে পারবে
- **কেন্দ্রীয় এডমিন** — সব যেলার লাইভ তালিকা (প্রতি ১৫ সেকেন্ডে স্বয়ংক্রিয় হালনাগাদ), সার্চ, ফিল্টার, সব তথ্য সম্পাদনা/মুছে ফেলা,
  Excel (CSV) ডাউনলোড, সাংগঠনিক যেলা ও এডমিন অ্যাকাউন্ট ব্যবস্থাপনা

### সাংগঠনিক যেলা কীভাবে কাজ করে
সাংগঠনিক যেলা (যেমন "ময়মনসিংহ দক্ষিণ") প্রশাসনিক যেলা নয় — কয়েকটি উপযেলা নিয়ে গঠিত। কেন্দ্রীয় এডমিন
"সাংগঠনিক যেলা" পেজে প্রতিটি যেলার অধীনস্থ উপযেলা নির্ধারণ করবেন। সদস্যের **বর্তমান ঠিকানার উপযেলা** দেখে সদস্য
স্বয়ংক্রিয়ভাবে সেই যেলায় যুক্ত হয় এবং সেই যেলার এডমিন তাকে দেখতে পান। কোনো যেলায় না পড়লে "যেলা নির্ধারিত হয়নি"
তালিকায় থাকে (শুধু কেন্দ্রীয় এডমিন দেখেন)। কেন্দ্রীয় এডমিন চাইলে কোনো সদস্যের যেলা হাতে নির্ধারণ করতে পারেন।

প্রথমবার চালু হলে নমুনা হিসেবে "ময়মনসিংহ দক্ষিণ" যেলা (ময়মনসিংহ সদর, ত্রিশাল, ফুলবাড়িয়া, ভালুকা, গফরগাঁও, মুক্তাগাছা) তৈরি হয়।

## চালানোর নিয়ম (ডেভেলপমেন্ট)

### ১. Backend
JDK 17 বা তার বেশি লাগবে (`JAVA_HOME` অবশ্যই JDK 17+ এ সেট থাকতে হবে)।

```bash
cd backend
mvn spring-boot:run
```
সার্ভার চলবে `http://localhost:8080` এ। ডিফল্টে ফাইল-ভিত্তিক H2 ডাটাবেজ (`backend/data/`) ব্যবহৃত হয় — আলাদা ডাটাবেজ লাগে না।

### ২. Frontend
Node.js 18.19+ / 20+ লাগবে।

```bash
cd frontend
npm install
npm start
```
ব্রাউজারে `http://localhost:4200` খুলুন। (`/api` রিকোয়েস্ট স্বয়ংক্রিয়ভাবে 8080 পোর্টে যায় — `proxy.conf.json`)

### ডিফল্ট লগইন (প্রথমবার চালুর পর অবশ্যই পাসওয়ার্ড পরিবর্তন করুন)

| ভূমিকা | ইউজারনেম | পাসওয়ার্ড |
|---|---|---|
| কেন্দ্রীয় এডমিন | `admin` | `admin@123` |
| ময়মনসিংহ দক্ষিণ যেলা এডমিন | `mymensingh-south` | `zila@123` |

এডমিন প্যানেল: `http://localhost:4200/admin`

## প্রোডাকশন ডিপ্লয় (একটি JAR ফাইলে)

```bash
# ১. Angular বিল্ড করে Spring Boot এর static ফোল্ডারে কপি
cd frontend && npm ci && npx ng build
mkdir -p ../backend/src/main/resources/static
cp -r dist/jubosongho/browser/* ../backend/src/main/resources/static/

# ২. JAR তৈরি
cd ../backend && mvn -DskipTests package

# ৩. PostgreSQL সহ চালানো
export SPRING_PROFILES_ACTIVE=prod
export DB_URL=jdbc:postgresql://localhost:5432/jubosongho DB_USERNAME=... DB_PASSWORD=...
export JWT_SECRET='কমপক্ষে-৩২-অক্ষরের-একটি-গোপন-লম্বা-স্ট্রিং'
export SUPER_ADMIN_PASSWORD='শক্তিশালী-পাসওয়ার্ড'
java -jar target/membership-1.0.0.jar
```
তারপর `https://আপনার-ডোমেইন/` হলো পাবলিক ফরমের লিংক, `https://আপনার-ডোমেইন/admin` এডমিন প্যানেল।
HTTPS (যেমন Nginx + Let's Encrypt) এর পেছনে চালানো আবশ্যক।

| Environment variable | কাজ |
|---|---|
| `JWT_SECRET` | লগইন টোকেনের গোপন চাবি (প্রোডাকশনে অবশ্যই বদলাবেন) |
| `SUPER_ADMIN_USERNAME` / `SUPER_ADMIN_PASSWORD` | প্রথম চালুতে কেন্দ্রীয় এডমিন |
| `SAMPLE_ZILA_ADMIN_PASSWORD` | নমুনা যেলা এডমিনের পাসওয়ার্ড |
| `CORS_ORIGINS` | ফ্রন্টএন্ড আলাদা ডোমেইনে থাকলে (কমা দিয়ে একাধিক) |
| `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` | `prod` প্রোফাইলে PostgreSQL |
